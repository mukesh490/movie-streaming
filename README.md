# Movie Streaming App

A modern and responsive Movie Streaming web application built with **React.js** and **Vite** using the **TMDB API**.

## Features

- Responsive Navbar
- Hero Banner
- Featured Movies Showcase
- Trending Movies
- Popular Movies
- Upcoming Movies
- Movie Details Page
- Search Movies
- Smooth Scroll Navigation
- Loading Skeleton
- Custom 404 Error Page
- Framer Motion Animations
- Responsive Design

## Tech Stack

- React.js
- Vite
- React Router DOM
- Tailwind CSS
- Framer Motion
- Axios
- Lucide React
- React Icons
- TMDB API

## Screens

- Home Page
- Featured Movies
- Trending Movies
- Popular Movies
- Upcoming Movies
- Search Page
- Movie Details
- Error Page

## Installation

Clone the repository:
https://github.com/mukesh490/movie-streaming

Install dependencies:

npm install

Start the development server:

npm run dev
